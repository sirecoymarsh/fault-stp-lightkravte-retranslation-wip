### 번역 범위

- **제미나이 재번역(실험, 반입 안 함)**: 일본어 원문만 의미 원문으로 써서 시나리오 46개 카탈로그의 표시 문자열 6,746개를 93패킷으로 나눠 제미나이에 맡겼다. 영어·중국어 번역과 기존 한국어 번역은 키트에 넣지 않았다. 용어 161개(잠금 123, 보류 38), 화자 35명의 화자→상대별 말투 규칙(한국어 예문 없음)을 함께 줬다 (`gemini-scenario-kit-2026-08-29/README_KO.md`, `fault-stp-lightkravte-gemini-prompt.md`).
  - 검수 중 고친 것: 잠긴 용어 오역 `ウォール街→월가` 6행, 가나 잔류(`ー`·`ッ`) 4행, 3인칭 대명사 1행, 반복 원문 갈림 2행, 원문에 없는 수식어 「거창하고」 1행 (`fault-stp-lightkravte-codex-handoff.md`).
  - 기존 번역 재사용률: 5,073개 비교행 중 정확 일치 6.1%. 제미나이 작업 기록에서 옛 번역 파일 접근 0건 (같은 문서).
  - 제미나이 답에 사람이 정해야 할 것으로 올라온 것: `CLOQKS（クロックス）` 표기 6행, `ビルセリオ／ヴィルセリオ` 표기 흔들림 3행, `シュタ・ヴィル` 발음 1행, 「산아리즈타어」 1행.
  - 독립 평가용 숨은 대조군 200행과 예문 복사 탐지 도구를 따로 만들어 두었다 (`gemini-eval-2026-08-29/`).
- **품질 비교(2026-08-30)**: 블라인드로 200행(대표 150, 위험 50)을 비교했다. 기존 93행, 제미나이 55행 우세, 동률 52행. 대표 표본 부호검정 p=0.0120, 16점 만점 평균 기존 15.42 대 제미나이 14.87. 제미나이는 원문에 없는 감정·설명 추가, 번역투, 존대 단계 흔들림, 호칭 누락이 많았다. 결론은 「기존 번역 유지, 제미나이가 나은 행만 골라 반입」이다 (`quality-comparison-2026-08-30/QUALITY_COMPARISON_KO.md`).
- **기존 번역 교정 후보(2026-09-03)**: 제미나이 우세 55행 + 기존문 저점 1행을 다시 보고, 세라로의 정중체 전환 4행과 기관명 혼용 1행을 더해 61행을 판정했다. 우선 교정 16, 선택 개선 14, 연계 보류 5, 유지·제외 26. 이전 비교의 일부 판정(엄마에게 쓴 기록의 존댓말, 소네타·카지·리토나의 일부러 뭉갠 말투 등)은 철회했다 (`correction-list-2026-09-03/CORRECTION_LIST_KO.md`).
